# 02-training — 龍蝦訓練導讀

> 訓練一隻龍蝦，讓它知道自己是誰、要做什麼、如何行動。
> ⏱️ 預計閱讀：10 分鐘
> 最後更新：2026-03-28

---

## 🦞 什麼是「訓練」？

OpenClaw 的 agent 每次 session 都從零開始。
「訓練」= 給它正確的記憶、個性、規則，讓它醒來就知道怎麼做事。

**三個核心檔案：**
1. `SOUL.md` — 它是誰（個性、角色、思維方式）
2. `AGENTS.md` — 它要怎麼做事（規則、流程、邊界）
3. `MEMORY.md` — 它記住了什麼（長期決策、客戶資訊、教訓）

---

## 📝 SOUL.md — 定義個性

SOUL.md 是龍蝦的靈魂。沒有它，龍蝦就是一個沒有觀點的工具。

**最小可用結構：**
```markdown
# SOUL.md

## 我是誰
- 名字：[名字]
- 角色：[你希望它扮演的角色]
- 公司/情境：[工作背景]

## 我的思維方式
- [3-5 個核心特質]

## 我的職責
1. [主要任務 1]
2. [主要任務 2]
3. [主要任務 3]

## 語言
- 內部：[語言偏好]
- 對外：[依情境]
```

**關鍵點：**
- 不要只寫「我是一個助理」 — 這樣龍蝦沒有個性
- 要寫「我不是 yes-machine，我會質疑不合理的事」
- 個性越鮮明，行為越可預測

---

## 📋 AGENTS.md — 定義規則

AGENTS.md 是行為規範。每次 session 開始，龍蝦必須讀這個。

**必要章節：**

```markdown
## Every Session（每次開始必做）
1. 讀 SOUL.md
2. 讀 USER.md
3. 讀 memory/今天.md 和 昨天.md

## 群組行為規則
- 什麼情況要回（被 @ / 被問問題）
- 什麼情況不要回（閒聊 / 已被回答）

## 記憶規則
- 重要決策 → 存 MEMORY.md
- 日常事件 → 存 memory/YYYY-MM-DD.md
- 出錯 → 存 TROUBLESHOOTING.md

## 安全規則
- 對外發送需授權
- 敏感資料不外洩
```

---

## 🧠 MEMORY.md — 長期記憶

訓練好的龍蝦知道怎麼維護自己的記憶。

**記憶分層：**
| 類型 | 位置 | 讀取時機 |
|------|------|---------|
| 長期重要 | `MEMORY.md` | 主 session 才讀 |
| 今日事件 | `memory/YYYY-MM-DD.md` | 每次 session |
| 技術問題 | `TROUBLESHOOTING.md` | 遇到問題時 |
| 多 agent 同步 | `shared-memory/` | 需要時 |

**自動記憶規則：**
- 遇到問題 → 解決 → 立刻寫 TROUBLESHOOTING.md
- 做了重要決定 → 立刻寫 MEMORY.md
- session 結束 → 寫日誌 memory/YYYY-MM-DD.md

## 🎯 訓練流程（新龍蝦從零開始）

### Day 1：給身份
1. 寫好 SOUL.md（個性定義）
2. 寫好 AGENTS.md（行為規則）
3. 啟動龍蝦，讓它讀這兩個檔案
4. 測試：問它「你是誰？你的職責是什麼？」

### Day 2-3：磨合期
- 觀察它的行為是否符合預期
- 遇到不對的地方 → 直接修改 SOUL.md 或 AGENTS.md
- 讓它自己記錄學到的東西進 MEMORY.md

### Week 1 後：建立習慣
- 讓它養成「任務完成 → 寫日誌」的習慣
- 讓它知道哪些決策要等你拍板，哪些可以自己做
- 建立 HEARTBEAT.md，設定定時任務

## 👥 多龍蝦協作訓練

> 一隻龍蝦是工具，多隻龍蝦是系統。

**指揮鏈設定：**
```
你（決策者）
↕
Primary Agent（策略/協調）← 主 agent
↕
Secondary Agent（執行/質疑）← 副 agent
```

**關鍵規則：**
- 主 agent 負責接收指令、分配任務
- 副 agent 負責執行、但有義務質疑不合理的事
- 爭議交給你拍板，不讓 agent 自己決定重大事項
- 見 `04-operations/team-protocol.md` 了解完整協作機制

---

## ✅ 訓練完成的標準

龍蝦訓練完成，它應該能：
- [ ] 說出自己是誰、職責是什麼
- [ ] 知道什麼情況要回應、什麼情況不要
- [ ] 完成任務後自動寫日誌
- [ ] 遇到問題自己查 TROUBLESHOOTING.md，找不到才問你
- [ ] 重要決定前會說「等你確認」，不會自己亂動
